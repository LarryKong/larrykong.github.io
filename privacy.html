Privacy policy

mcp-google-multi. Last updated 17 September 2026.

mcp-google-multi is a personal command-line tool operated by Laurence Kong. It runs locally and accesses only the Google accounts its operator owns. It has no other users, collects nothing from anyone else, and runs no hosted service.

What the tool accesses

At sign-in the tool asks for these Google OAuth scopes. Nothing outside this list is requested.

ScopeWhat it allows
gmail.modifyRead messages, and change labels and read state
gmail.sendSend a message the operator has composed
gmail.settings.basicRead and write filters and vacation settings
driveRead and write Drive files
calendarRead and write calendar events
spreadsheetsRead and write Google Sheets
documentsRead and write Google Docs
contactsRead and write contacts
tasksRead and write Google Tasks
webmastersRead Search Console data
meetings.space.readonlyRead Meet space details

How the data is used

Data fetched from these APIs is passed to the local AI assistant that asked for it, in order to answer the operator's own question. That is its only purpose. The tool does not profile anyone, serve advertising, or make automated decisions about people.

What is stored, and where

  • OAuth refresh and access tokens are encrypted with a local key and written to the operator's own filesystem. They are per-machine and are never uploaded anywhere.
  • Message bodies, files and calendar entries are not copied into any database. They are held in memory for the duration of a request and discarded.
  • There is no analytics, no telemetry and no logging to any remote service.

What is shared

Nothing is sold, rented or transferred to a third party. The only parties that see the data are Google, whose APIs supply it, and the AI assistant running locally that the operator directed to read it.

Limited use

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revoking access

Tokens are kept until they expire or are revoked. Access can be withdrawn at any time from Google Account permissions, which immediately invalidates the stored tokens. Deleting the local token directory has the same effect on that machine.

Children

The tool is not directed at children and is not usable by anyone other than its operator.

Changes

If the scopes or the handling described here change, this page is updated and the date at the top changes with it.
