mcp-google-multi

A personal tool for reaching my own Google Workspace data from local AI tooling.

mcp-google-multi is a command-line program I run on my own computers. It exposes Gmail, Drive, Calendar and Sheets to a local AI assistant through the Model Context Protocol, so I can search my mail, read a spreadsheet or check my calendar without leaving the terminal.

Who can use it

This is a single-operator project with no sign-up and no hosted service. It runs only on machines I control, and it connects only to Google accounts I own. There is nothing here to install or subscribe to.

How it runs

  • The program runs as a local process. There is no server component and no backend that I operate.
  • It talks directly to Google's APIs from my machine, using OAuth credentials I granted to my own accounts.
  • Access tokens are encrypted and stored on the local filesystem. They never leave the machine that created them.

Privacy

The privacy policy describes exactly which Google scopes the tool requests, what it does with the data, and how to revoke its access.
